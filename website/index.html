Features

Everything to take a renovation from blueprint to final walkthrough.

📋 Project Dashboard

Budget vs actual, timeline % complete, contractor rating, status, critical path at a glance.

✅ Task Management

Kanban board with dependencies, assignees, due dates, photos, checklists, critical path highlighting.

💰 Budget Tracking

Line-item budgets, expense tracking, variance alerts, payment schedules, lien waivers, change orders.

👷 Contractor Portal

Invite contractors to update progress, upload photos, request payments, view specs, communicate.

📁 Document Vault

Contracts, permits, receipts, designs, specs. Versioned, searchable, OCR, sharing with permissions.

📅 Timeline Views

Gantt charts, milestone tracking, critical path, baseline vs actual, weather delays, resource leveling.

Tech Stack

Modern, type-safe, deployable anywhere.

Next.js 14+ (App Router)

Server Components, Server Actions, Streaming, Suspense, Middleware, ISR

Prisma ORM

Type-safe database access, migrations, seeding, Prisma Studio, connection pooling

TypeScript (Strict)

End-to-end type safety, tRPC for APIs, Zod validation, Branded types for IDs

Tailwind CSS

Utility-first, dark mode, design tokens, component library, responsive

PostgreSQL

JSONB for flexible specs, PostGIS for site locations, advisory locks for concurrency

Docker + Compose

One-command dev stack, production-ready, multi-stage builds, health checks

tRPC + React Query

End-to-end typesafe APIs, caching, invalidation, optimistic updates

NextAuth.js

Email magic links, OAuth (Google/GitHub), RBAC, session management

Project Workflow

From estimate to final payment.

1. Estimate & Contract

Create project → Add line items
→ Generate contract → E-sign
→ Setup payment schedule

2. Permits & Planning

Upload permits → Set milestones
→ Invite contractors → Assign tasks
→ Baseline timeline

3. Execution

Daily logs → Photo uploads
→ Progress % → Budget tracking
→ Change orders → Approvals

4. Completion

Punch list → Final inspection
→ Lien waivers → Final payment
→ Warranty docs → Handoff
