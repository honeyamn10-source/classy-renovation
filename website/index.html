Features

Project Dashboard

Overview of budget, timeline, contractor, and status at a glance.

Task Management

Kanban-style task board with dependencies, assignees, and due dates.

Budget Tracking

Line-item budgets, expense tracking, variance alerts, payment schedules.

Contractor Portal

Invite contractors to update progress, upload photos, request payments.

Document Vault

Store contracts, permits, receipts, designs. Versioned and searchable.

Timeline Views

Gantt charts, milestone tracking, critical path highlighting.

Tech Stack

Next.js 14+

App Router, Server Components, Server Actions

Prisma ORM

Type-safe database access with PostgreSQL

TypeScript

Strict mode, end-to-end type safety

Tailwind CSS

Utility-first styling with dark mode

Docker

Containerized deployment with docker-compose

ESLint + Prettier

Consistent code style and formatting
